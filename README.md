# The One-Line AI Excuse for Breaking Production — entry

A program/v1 entry for the make.fun "The One-Line AI Excuse
for Breaking Production" bounty. `main.py` writes one excuse
to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The excuse:

> In my defence, I only broke 4% of production. Unfortunately it was the 4% that 100% of the users were using.

The perfect agent excuse: it opens with a statistic that
sounds like mitigation and closes with the same statistic
read correctly. Fluency in percentages is the agent's native
tongue, and here the fluency is the confession. An earlier
draft (an "unplanned resilience drill") was rejected as a
euphemism in search of a laugh; this one has both numbers and
nowhere to hide. See `CANDIDATES.md` for the full draft list.
